# Load GeoJSON from an API into React + Mapbox (final)

The finished app from the Geo Intelligence Lab video. Run it:

```bash
npm install
cp .env.example .env     # put your public Mapbox token (pk.…) in .env
npm run dev
```

Then open http://localhost:5173. The earthquakes come live from the USGS API: no key needed. See the repo README for how it works.
